Una interpretación de fantasía medieval: ocho rayos de bronce sobre un cuerpo de roble, protegido por un aro de acero y veinticuatro remaches. Gíralo para descubrir el asa del reverso.

El detalle fino vive en las texturas; la geometría define la silueta. Los tres materiales se pueden transformar de forma independiente.

01 / Forma y UVs +

Modelado procedural original con bordes biselados, umbo central y asa. Proyección planar para el cuerpo y paramétrica para las piezas circulares. Las piezas repetidas comparten espacio UV.

02 / Superficies PBR +

Base Color, Roughness, Metallic y Normal en 512 × 512 px. El GLB combina rugosidad y metalicidad en una textura: canal G = Roughness, canal B = Metallic. Los normales usan la convención OpenGL.

03 / Listo para la web +

GLB autocontenido con UVs, normales y tangentes. Tres materiales, tres primitivas y controles de apariencia mediante la API de materiales de Google model-viewer.
